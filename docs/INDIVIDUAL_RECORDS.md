# 按人读取加密报告

历次成绩和小题累计后，完整发布包可能达到数MB。查询页支持读取一位学生对应的加密文件，减少首次查询下载量。

`data/version.json`可包含：

- `recordBasePath`：形如`data/records/<dataVersion>/`的相对目录，版本目录发布后不覆盖。
- `recordHashes`：以v3慢哈希地址为键、加密记录JSON的SHA-256为值。其数量必须与`recordCount`相同。

每个`<fileId>.json`保存原发布包中对应的`{v:3,salt,iv,data}`，不包含明文报告。哈希按`JSON.stringify(record)`计算。姓名及查询信息仍先经过240000次PBKDF2派生地址和密钥；查询页核对文件摘要后再用AES-GCM解密。错误凭据不读取其他人的记录。

主入口和`student-results/`各自包含相同的版本索引及加密文件。完整`grade-data.v2.json`保留，用于备份、旧版本兼容和批量校验。查询页在索引提供上述字段时直接读取个人文件，不会先下载完整包；文件缺失或摘要不符会提示更新中。

没有这些字段的发布包继续使用原有完整包流程。现有浏览器发布工作台生成的包仍然兼容；如使用CLI启用个人文件模式，应同步提交个人文件、摘要索引和两个查询入口，避免只提交版本索引而漏掉文件。
