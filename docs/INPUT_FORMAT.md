# 成绩发布输入格式 v2

本项目的工作流是：

```text
填写本次考试模板 → publisher.html 导入 → 空值归一化 → 字段校验 → 合并项目备份 → 浏览器端加密 → 一键提交 GitHub → Pages 自动更新
```

## 最简单的使用方式

1. 打开 [成绩发布工作台](../publisher.html)。日常使用推荐直接打开 GitHub Pages 上的工作台；完整图文步骤也可查看 [网页使用说明](../guide.html)。如果需要本地运行，请在仓库目录执行 `python -m http.server 8080` 后打开 `http://localhost:8080/publisher.html`。
2. 下载 `templates/exam-template.xlsx`，在 Excel 中填写本次考试数据。
3. 删除模板中的示例学生，填入真实学生记录。
4. 导入 Excel，处理工作台给出的错误或提醒。
5. 第一次考试直接生成；以后考试先导入上一次下载的 `grade-project-*.json` 项目备份，再导入本次考试模板。工作台会先显示合并后的考试数、学生数，并明确提示同编号覆盖。
6. 点击“生成加密发布包”，输入 GitHub Fine-grained Token，点击“一键上传并发布”。

工作台会拒绝超过 12 MB 的考试文件和超过 24 MB 的项目备份；若 Excel 体积过大，请先删除无关图片、隐藏工作表和多余格式。模板示例学生（如 `TEST001`）也会阻止发布，避免把演示记录误传到公开仓库。

## Excel 工作表

### 1. `考试信息`

第一列填写字段，第二列填写值。字段如下：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `考试编号` | 是 | 唯一编号，例如 `2026-zero`；再次使用同一编号会覆盖该场考试。 |
| `考试名称` | 是 | 家长报告中显示的名称。 |
| `考试日期` | 否 | 推荐使用 `YYYY-MM-DD`。 |
| `排名范围` | 否 | `city` / `全市`、`school` / `校内`、`class` / `班级`。 |
| `班级名称` | 是 | 例如 `高二4班`。 |
| `特控线` | 否 | 本次总分特控线；留空则不显示总分特控线差。 |
| `本科线` | 否 | 本次总分本科线；留空则不显示总分本科线差。 |
| `备注` | 否 | 例如 `物理类`。 |

### 2. `科目分数线`

每一行一个科目：`科目键`、`科目名称`、`满分`、`特控线`、`本科线`。科目键固定使用：

`chinese`、`math`、`english`、`physics`、`chemistry`、`biology`

科目线可以留空。留空时仍然显示科目分数和排名，但不计算该科目的线差。

### 3. `学生成绩`

每一行一个学生。必填字段：

| 字段 | 说明 |
| --- | --- |
| `学号` | 查询识别码。请使用 8 位以上随机字母数字组合（发布台可一键生成），不要使用身份证号或 ≤10 位纯数字学号——公开页面上的数据可被离线穷举，识别码熵越高越安全。 |
| `姓名` | 学生姓名。 |
| `班级` | 可留空，留空时使用考试信息中的班级。 |
| `总分` | 可留空；留空时按已填写科目分数自动计算。 |
| `全市排名`、`校内排名`、`班级排名` | 没有对应范围时留空。排名必须是正整数。 |
| `语文分数` 等科目分数 | 0 是有效分数；空白才表示缺失。 |
| `语文排名` 等科目排名 | 可留空，必须是正整数。 |

支持的科目列为：语文、数学、英语、物理、化学、生物。模板使用中文列名；JSON 可以使用英文键名。

### 4. `知识点失分`

可选字段：`学号`、`科目键`、`知识点`、`题号`、`失分`。一行代表一条主要失分记录。工作台会把同一学生的记录合并到报告中的“小题与知识点”。

## 空值规则

- 空白、`—`、`-`、`无`、`暂无`、`null` 会归一化为空值；
- 数字 `0` 会保留，不会被当成空值；
- 总分为空但存在科目分数时，自动计算已填写科目合计；
- 总分已填写但与科目合计不同，只产生提醒，不会擅自改写总分；
- 分数超出科目满分、排名不是正整数、查询识别码重复，会阻止生成。
- 合并历史项目时，本次缺席的历史学生会保留原报告但不会新增本次记录；同一查询识别码姓名发生变化时会明确提醒检查错配。

## 项目备份与加密发布包

项目备份 `grade-project-*.json` 是下一次合并历史考试所需的明文工作文件，只应保存在自己的电脑或加密存储中，不要上传到公开仓库。

发布包只包含：

- `data/grade-data.v2.json`：每位学生独立随机盐和 IV 的 AES-GCM 加密记录；
- `data/version.json`：版本、考试数量、学生数量、生成时间和发布包 SHA-256 校验值。

生成完成后，工作台会显示 `releaseId`、加密记录数量和校验值。上传到 GitHub 后会回读 `data/version.json`，确认远端版本与本次生成的发布包一致；Pages 仍需要等待 GitHub 完成构建。

查询页会优先读取 v2 发布包；仓库还没有 v2 发布包时，才兼容读取旧版逐文件数据。一旦发现有效的 v2 发布包，未匹配到的学生不会再回退到可能过期的旧记录。读取 v2 数据时会核对版本号、SHA-256 和加密记录数量；Pages 更新过程中两个文件尚未同步时，页面会提示稍后刷新，不会把新旧版本混合展示。

## 一键上传所需权限

创建 GitHub Fine-grained Token 时：

- Repository access：只选择 `yusheng266186-beep/grade-query`；
- Repository permissions：`Contents: Read and write`；
- 不要把 Token 填进模板或提交到仓库；
- 工作台只在当前页面内存中使用 Token，上传完成或失败后会清空输入框。
