# 手机成绩报告与名次趋势

两个查询入口使用相同的`report-metrics.js`、`report-layout.css`和小题展示组件。资源链接使用版本参数，避免旧样式与新页面混用。

## 名次数据

成绩复盘工作簿中部分固定位置的“校名”值与实际范围不一致，不能直接作为年级名次曲线。本次发布保留原有分数、原有排名字段、查询凭据及历史记录，另补充：

- 每次考试的`gradeRanks`：总分及各科在同次、本校物理类、表内有效成绩中的并列名次。
- `gradeCounts`：各指标实际参与排序的人数，科目缺失成绩不参与。
- `gradeRankScope: "school-physics"`：明确比较范围，避免把市排或班排放进年级曲线。
- 当前报告的`current.gradeRank`及各科`gradeRank`、`gradeCount`，用于概览与学科卡片。

同分并列，后续跳位。总分及化学、生物使用表内赋分，其他学科使用原始科目成绩。每个分值与原报告逐项核对后才加入名次；缺失分数保留空值。重排范围限于原表，不能据此声称是原始官方校排。页面同时展示本场人数及统计口径。

本次期中考试有一条经老师确认的考生身份更正，使用已确认的原表记录定位来源，两人的历史成绩分别保留。

## 图形与排版

曲线纵坐标为选中科目的年级名次，数值越小越靠上；分数作为辅助明细保留。切换科目同时更新曲线、人数、分数和考次卡片。缺失名次保留原时间位置并断线，不连接不同范围的数据。只有一次有效记录时显示单点。

图表支持触摸、鼠标、左右方向键与考次卡片选择。阶段变化文字同样采用同范围名次，不把卷面分数增加直接当作进步。

缺失市排名、科目名次及分数线信息不渲染空占位。学科表现与历次总分名次采用一行一条的矩形布局，考次明细横向滚动，操作按钮放在内容末尾，避免覆盖曲线或题目。

小题按学科折叠，每题采用一行一个矩形条，直接显示题号、知识点与得分。提供全部、有失分和满分筛选，未录入与真实0分分开处理。移除逐题的待核对标记和对应筛选；原表未确认题号或满分的情况在学科内集中说明，仍不计算这些小题的失分或得分率。

## 验证

`tools/report-metrics-regression.mjs`验证名次反向坐标、科目独立取数、范围隔离、缺失位置、0分和单点。原有加密查询及小题导入回归继续运行。真实数据验证包括两个入口全部50份报告、不同手机和桌面宽度、筛选和触摸选择，并核对全部分数、小题与凭据保持一致。

统计与图形处理参考[jianwei-observatory](https://github.com/yusheng266186-beep/jianwei-observatory)的`ranking.js`、`research-history.js`与`plot-scale.js`：明确名次范围，名次轴反向，缺失数据不冒充有效值。小题仅在明确满分时计算失分。
