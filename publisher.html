Token 需要什么权限？

创建 Fine-grained Token 时，将 Repository access 限定为 yusheng266186-beep/grade-query，Repository permissions 只开启 Contents: Read and write。如果仓库启用了严格的 Pages 管理权限，再额外开启 Pages: Read；本工作台不会把 Token 保存到仓库。
